# 🎮 CubeWorld - Android Game

Minetest tabanlı bir sandbox oyun platformu. Kendi haritanı oluştur, oyna ve keyfini çıkar!

## 📱 İndirme

**[EN SON APK İNDİR](https://github.com/ahmedemintokgoz2510-ctrl/CubeWorld/releases/latest)**

### Kurulum Adımları:
1. APK dosyasını indir
2. Bilgisayartan telefonuna aktar VEYA direkt telefondan indir
3. Bilinmeyen kaynaklardan kuruluma izin ver (Ayarlar > Güvenlik)
4. Yükle ve oyna! 🚀

## 🎯 Özellikler

✨ Açık dünya sandbox oyunu  
🏗️ Blok tabanlı inşaa sistemi  
🎨 Özelleştirilebilir dünya  
⚡ Performans optimize  
📦 Offline oynanabilir  

## 💻 Teknik Bilgiler

- **Motor:** Minetest Engine
- **Dil:** Lua
- **Platform:** Android 5.0+
- **Boyut:** ~50MB (optimize edilmiş)

## 🔧 Geliştirme

```bash
git clone https://github.com/ahmedemintokgoz2510-ctrl/CubeWorld.git
cd CubeWorld
```

### Build Gereklilikler
- Android SDK 30+
- Java 11+
- Gradle 7.5+

### Build Et
```bash
./gradlew assembleRelease
```

APK dosyası `app/build/outputs/apk/release/` klasöründe oluşacak.

## 📋 Sistem Gereksinimleri

- **Minimum:** Android 5.0 (API 21)
- **Önerilen:** Android 8.0+ (API 26+)
- **RAM:** 2GB minimum
- **Depolama:** 100MB boş alan

## 🎮 Kontroller

| Tuş | İşlem |
|-----|-------|
| W,A,S,D | Hareket |
| Boşluk | Zıpla |
| Sol Tık | Blok Kır |
| Sağ Tık | Blok Koy |
| E | Envanteri Aç |
| ESC | Menü |
